# Mitologia App — ⚠️ Projeto sem código-fonte

Não foi possível rodar nem capturar prints deste projeto porque **ele não
contém código-fonte**. A pasta `mitologia_app/mitologia_app/` possui apenas:

- `analysis_options.yaml`
- uma pasta `build/` com artefatos de compilação antigos

Faltam os itens essenciais de um projeto Flutter executável:

- `pubspec.yaml`
- pasta `lib/` (com `main.dart` e demais telas)
- plataformas (`android/`, `web/`, etc.)

## O que fazer para liberar a demonstração

Escolha uma das opções:

1. **Enviar o código-fonte** (a pasta `lib/` e o `pubspec.yaml` do projeto
   original). Com isso eu consigo rodar e gerar os prints.
2. **Recriar a estrutura do zero** — posso scaffoldar um novo projeto Flutter
   nesta pasta e implementar o app de mitologia conforme o enunciado da
   Atividade 2. Para isso, preciso que você me passe o enunciado/requisitos
   (o que o app deve mostrar e fazer).

Assim que você me passar o código ou os requisitos, eu rodo o app e adiciono
os prints aqui, igual aos outros projetos.
